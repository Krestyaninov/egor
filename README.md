# Egor — CRM & Marketing Analyst Telegram Bot

AI-ассистент сквозной аналитики CRM и воронки продаж для магазина электроники.

## 🚀 Возможности
- 📊 **Пульс дня:** Входящие заказы, квалификация лидов, выкуп день-в-день и конверсия.
- 💰 **Сквозная маржинальность:** Расчет чистой прибыли по выкупленным категориям.
- 🛑 **Причины отказов:** Анализ срывов сделок с точными суммами потерь выручки.
- ⏳ **Pipeline:** Контроль зависших заказов в работе старше 24 часов.
- ⏰ **Авто-дайджесты:** Утренний отчет в 09:00 и вечерний срез в 21:00 МСК.

## 🛠 Запуск в Docker
```bash
docker compose up -d --build
```
