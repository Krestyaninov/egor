# Egor — CRM & Marketing Analyst Telegram Bot

Персональный AI-ассистент сквозной аналитики CRM Битрикс24 и воронки продаж для интернет-магазина техники.

Бот в Telegram: **[@egor_quapmi_bot](https://t.me/egor_quapmi_bot)**

---

## 🔒 Безопасность и модель авторизации (Invite-Only)

- **Главный Администратор (ID `78429883`):** имеет постоянный доступ и панель управления `⚙️ Доступы & Сотрудники`.
- **Одноразовые пароли / инвайт-ссылки:** админ генерирует 6-значный пароль и отправляет сотруднику (например, `https://t.me/egor_quapmi_bot?start=X7K9LP`).
- **Защита данных:** посторонние пользователи без приглашения блокируются и не видят коммерческую информацию.
- **Управление доступом:** админ может в любой момент посмотреть список сотрудников и отозвать доступ.

## 🎯 Возможности и отчеты

| Отчет / Команда | Описание |
| :--- | :--- |
| **📊 `Сегодня (Пульс)`** (`/today`) | Входящий поток, квалификация лидов, выкуп день-в-день, промежуточный пайплайн и отказы |
| **🌅 `Вчера (Итоги)`** (`/yesterday`) | Итоги прошедшего дня с чистой воронкой и конверсией в выкуп |
| **📈 `Графики & Динамика`** (`/charts`) | 3 аналитические диаграммы: спрос, доля квалификации (цель 95%) и кассовая выручка WON |
| **🗓 `Недельный отчет (7 дней)`** (`/week`) | Сводка за 7 полных закрытых дней (D-7 ... D-1) |
| **🏷 `Продажи по товарам`** (`/products`) | Аналитика по типам товаров (Apple vs Другие) за Вчера, Тек. неделю, Прошлую неделю, Тек. месяц, Прошлый месяц + диаграммы |
| **⭕️ `Нулевые сделки`** (`/zero`) | Контроль лидов с 0 ₽ (без спама): динамика по дням (7 дней) и неделям (5 недель) + график (столбцы + % квала) |
| **⏳ `Зависшие сделки (>48ч)`** (`/pipeline`) | Структура зависших заказов в работе по статусам и суммам |
| **🛑 `Причины отказов`** (`/reasons`) | Топ причин срывов сделок за 7 закрытых дней с суммами упущенной выручки |
| **⚙️ `Доступы & Сотрудники`** (`/admin`) | Генерация паролей-приглашений, просмотр сотрудников и отзыв доступов |

### ⏰ Автоматический утренний пульс
- **Каждый день в 09:00 МСК:** Утренний дайджест за вчера, аудит зависшего пайплайна (>48ч) и автоматическая отправка инфографики за последние 7 дней (только авторизованным пользователям).
