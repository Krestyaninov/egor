# Egor — CRM & Marketing Analyst Telegram Bot

Персональный AI-ассистент сквозной аналитики CRM Битрикс24 и воронки продаж для интернет-магазина техники.

Бот в Telegram: **[@egor_quapmi_bot](https://t.me/egor_quapmi_bot)**

---

## 🎯 Возможности и отчеты

| Отчет / Команда | Описание |
| :--- | :--- |
| **📊 `Сегодня (Пульс)`** (`/today`) | Входящий поток, квалификация лидов, выкуп день-в-день, промежуточный пайплайн и отказы |
| **🌅 `Вчера (Итоги)`** (`/yesterday`) | Итоги вчерашнего дня с расчетом чистой прибыли и топ-категориями |
| **📱 `Категории & Маржа`** (`/categories`) | Сквозная маржинальность и чистая прибыль по направлениям за 7 дней |
| **🛑 `Причины отказов`** (`/reasons`) | Топ причин срывов сделок с суммами упущенной выручки |
| **⏳ `Зависшие сделки`** (`/pipeline`) | Контроль заказов в работе без движения старше 24 часов |
| **🗓 `Последние 7 дней`** (`/week`) | Недельный срез динамики продаж и конверсии воронки |

### ⏰ Автоматические дайджесты
- **09:00 МСК:** Утренний отчет за вчера с проверкой зависшего пайплайна.
- **21:00 МСК:** Вечерний срез выкупленной маржи по категориям.

---

## 🏗 Архитектура и стек

- **Язык:** Python 3.11
- **Фреймворк:** `aiogram 3.30`
- **Планировщик:** `APScheduler 3.11`
- **Интеграция:** Асинхронный REST API Битрикс24 (`aiohttp`)
- **Сетевой стек:** `aiohttp-socks` (SOCKS5 Proxy)
- **Контейнеризация:** Docker, Docker Compose

---

## 🚀 Развертывание и деплой

### Локальный запуск:
```bash
cp .env.example .env
# Заполните TELEGRAM_BOT_TOKEN и BITRIX_WEBHOOK_URL
python3 bot.py
```

### Запуск в Docker:
```bash
docker compose up -d --build
```

### Деплой на прод-сервер в 1 команду:
```bash
ssh root@147.45.211.75 "cd /opt/projects/egor && ./deploy.sh"
```

Полный регламент и архитектура описаны в [PROJECT_PASSPORT.md](PROJECT_PASSPORT.md).
