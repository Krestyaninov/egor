# Egor — CRM & Marketing Analyst Telegram Bot

Персональный AI-ассистент сквозной аналитики CRM Битрикс24 и воронки продаж для интернет-магазина техники.

Бот в Telegram: **[@egor_quapmi_bot](https://t.me/egor_quapmi_bot)**

---

## 🎯 Возможности и отчеты

| Отчет / Команда | Описание |
| :--- | :--- |
| **📊 `Сегодня (Пульс)`** (`/today`) | Входящий поток, квалификация лидов, выкуп день-в-день, промежуточный пайплайн и отказы |
| **🌅 `Вчера (Итоги)`** (`/yesterday`) | Итоги прошедшего дня с чистой воронкой и конверсией в выкуп |
| **📈 `Графики & Динамика`** (`/charts`) | 3 аналитические диаграммы: спрос, доля квалификации (цель 95%) и кассовая выручка WON |
| **🗓 `Недельный отчет (7 дней)`** (`/week`) | Сводка за 7 полных закрытых дней (D-7 ... D-1) |
| **⏳ `Зависшие сделки (>48ч)`** (`/pipeline`) | Структура зависших заказов в работе по статусам и суммам |
| **🛑 `Причины отказов`** (`/reasons`) | Топ причин срывов сделок за 7 закрытых дней с суммами упущенной выручки |

### ⏰ Автоматический утренний пульс
- **Каждый день в 09:00 МСК:** Утренний дайджест за вчера, аудит зависшего пайплайна (>48ч) и автоматическая отправка инфографики за последние 7 дней.

## 🏗 Архитектура и стек

- **Язык:** Python 3.11
- **Фреймворк:** `aiogram 3.30`
- **Визуализация:** `matplotlib 3.9`
- **Планировщик:** `APScheduler 3.11`
- **Интеграция:** Асинхронный REST API Битрикс24 (`aiohttp`)
- **Сетевой стек:** `aiohttp-socks` (SOCKS5 Proxy)
- **Контейнеризация:** Docker, Docker Compose
